---
description: ウォーターフォールのフェーズゲート審査を実施し、承認されたら次フェーズへ移行する
---

waterfall スキル（~/.claude/skills/waterfall/SKILL.md）を読み込み、フェーズゲート審査を
実施してください。

引数（任意）: $ARGUMENTS

手順:
1. docs/PROJECT_STATUS.md で現在フェーズを確認する。
2. スキルの「ゲート審査チェックリスト」（共通 + フェーズ別観点）に沿って
   現フェーズ成果物を実際に読み、項目ごとに合否を判定する。
   トレーサビリティ表と本文の ID を突合し、孤児 ID を検出する。
3. 審査結果を報告する: 合格 / 条件付き合格（条件を列挙） / 差し戻し（理由と修正案）。
4. 合格（または条件解消）の場合、**ユーザーに承認を確認**する。
   承認前に PROJECT_STATUS.md を書き換えないこと。
5. 承認されたら: 現フェーズを「承認済み」・ゲート通過日を記録し、
   次フェーズを「進行中」へ。次フェーズのドキュメントが未生成なら
   templates/ から生成し、最初の作業項目を提示する。
