# プリフライトチェックリスト（コミット / PR / 「完了」宣言の前）

各項目は**実際に実行・確認した結果**をもってチェックする。

## 検証ゲート
- [ ] テストスイートを実行し、全件通過した（実行コマンドと結果件数を記録）
- [ ] リンター/フォーマッタを実行し、指摘ゼロ
- [ ] 型チェックを実行し、エラーゼロ（該当言語）
- [ ] ビルドが通る（該当プロジェクト）

## 差分の自己レビュー（git diff を通読）
- [ ] 差分は1つの関心事に収まっている（混入した無関係変更がない）
- [ ] デバッグ用コード・print・コメントアウト残骸がない
- [ ] TODO を残す場合は Issue 化 or 状態ファイルに記録した
- [ ] 追加した公開 API / 変更した挙動にテストがある
- [ ] エラーパス（異常系）の挙動を確認した
- [ ] 秘密情報・内部ホスト名・個人情報が含まれていない
- [ ] 生成物・実行成果物（テストレポート、キャッシュ、ビルド出力）が混ざっていない
- [ ] 整形ツールを一括実行した場合、無関係なファイルに出た差分を戻した

## 整合性
- [ ] 仕様・設計ドキュメント（該当する場合）と実装が一致している
- [ ] 状態ファイル（PROJECT_STATUS.md / SPRINT.md 等）を更新した
- [ ] コミットメッセージが変更理由を説明し、関連 ID（REQ/PBI/DTL 等）を含む

## リスク
- [ ] 破壊的変更・マイグレーションがある場合、ロールバック手順を書いた
- [ ] 認証・認可・決済・個人情報に触れた場合、checklists/security.md を実施した

## 報告
- [ ] できなかったこと・スキップしたこと・残課題を報告に明記した

## マージ後（自分でマージした / マージされたと聞いた直後）
- [ ] 本流ブランチの**実体**を確認した（該当ファイルの存在、テスト件数、`git log`）
- [ ] PR の「MERGED」表示だけを根拠に完了と判断していない
