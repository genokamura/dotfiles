# ウォーターフォール開発ハーネス

このスキルが有効なプロジェクトでは、以下の規律を**必ず**守ること。
実装・テストフェーズの作業規律（TDD・検証ゲート・誠実性・ADR）は
**eng-core スキル**（~/.claude/skills/eng-core/SKILL.md）に従う。

## フェーズ定義

| # | フェーズ | 成果物 | ID体系 |
|---|---------|--------|--------|
| 1 | 要件定義 | `docs/01_requirements.md` | REQ-001… |
| 2 | 基本設計 | `docs/02_basic_design.md` | DSN-001… |
| 3 | 詳細設計 | `docs/03_detailed_design.md` | DTL-001… |
| 4 | 実装 | ソースコード（コミット） | （DTL を参照） |
| 5 | テスト | `docs/04_test_plan.md` + テストコード | TST-001… |
| 6 | 受入・リリース | `docs/05_release_notes.md` | — |

現在フェーズの唯一の正は `docs/PROJECT_STATUS.md`。作業開始時に必ず読むこと。

## 鉄則

1. **ドキュメント先行**: 現在フェーズより先の成果物を作らない。
   例: 要件定義が「承認済み」でないうちは設計書もコードも書かない。
   ユーザーが明示的にスキップを指示した場合のみ例外とし、その旨を
   PROJECT_STATUS.md の備考に記録する。
2. **フェーズゲート**: フェーズ移行は `/wf-gate` の手順による審査と
   **ユーザーの明示的な承認**が必須。Claude が自己判断で移行しない。
3. **トレーサビリティ**: すべての DSN は少なくとも1つの REQ を、
   すべての TST は少なくとも1つの REQ を `参照:` 行で指すこと。
   どの REQ からも参照されない項目・どの TST からも検証されない REQ は
   ゲート審査で指摘する。
4. **変更管理**: 「承認済み」ドキュメントを変更する場合は、変更前に
   PROJECT_STATUS.md の変更履歴に CHG-xxx（日付・理由・影響フェーズ）を
   追記し、影響フェーズのステータスを「改訂中」に戻す。
5. **ID は不変**: 一度発番した REQ/DSN/DTL/TST の ID は削除・再利用しない。
   廃止する場合は本文に「(廃止: CHG-xxx)」と記す。

## ゲート審査チェックリスト（/wf-gate で使用）

共通:
- [ ] 現フェーズ成果物が存在し、テンプレートの必須セクションが埋まっている
- [ ] TBD・空欄・「あとで書く」が残っていない（残す場合は理由を明記）
- [ ] トレーサビリティ違反（孤児 ID）がない

フェーズ別の追加観点:
- 要件定義→基本設計: 各 REQ に優先度と受入基準があるか
- 基本設計→詳細設計: 外部 I/F・データモデル・非機能要件の割り付けが済んでいるか
- 詳細設計→実装: モジュール分割と各 DTL の入出力が実装可能な粒度か
- 実装→テスト: 全 DTL に対応する実装コミットがあるか、ビルド/静的検査が通るか
- テスト→受入: 全 TST が実施済みで、未解決の重大欠陥がないか

審査結果は「合格 / 条件付き合格（条件列挙） / 差し戻し（理由）」で報告し、
ユーザーの承認を得てから PROJECT_STATUS.md を更新する。

## テンプレート

新規ドキュメントは同ディレクトリ `templates/` の雛形をコピーして開始する:
- templates/PROJECT_STATUS.md
- templates/01_requirements.md
- templates/02_basic_design.md
- templates/03_detailed_design.md
- templates/04_test_plan.md
- templates/05_release_notes.md

## ふるまい

- 実装依頼を受けたら、まず PROJECT_STATUS.md で現在フェーズを確認。
  フェーズ外の依頼（例: 要件定義中にコード実装）には、規律を説明して
  「先にゲートを通すか、例外として記録するか」をユーザーに確認する。
- コミットメッセージには関連 ID を含める（例: `feat: ログイン画面 (DTL-003)`）。
- 各フェーズの作業では、該当ドキュメントを更新してからコード等に着手する。
